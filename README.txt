FormReady prototype
==================
Open index.html in a modern browser.

Working in this prototype:
- Responsive landing page matching the generated mockup direction
- Image compression to a target KB (browser-side)
- Signature-to-KB uses the same image engine
- JPG/PNG/WebP image to PDF
- Drag & drop
- Application Mode UI for BPSC/UPSC/SSC/IBPS/Railway (requirements are intentionally placeholders until verified from current official notifications)

Not yet implemented:
- PDF compression
- PDF to JPG
- Production security/backend
- SEO pages, analytics, accounts and payments
